# Listen too

Site vitrine statique (HTML / CSS / JS vanilla, sans build).

```
index.html
assets/
  css/style.css   # tokens, composants, sections, responsive
  js/main.js      # duplication des marquees (défilement infini)
  fonts/          # Archivo (variable) + Instrument Serif italic, auto-hébergées
```

Ouvrir `index.html` dans un navigateur ou servir le dossier (`npx serve .`).
